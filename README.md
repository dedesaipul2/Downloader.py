## 🚀 Apa itu UltraProMax Downloader?

**UltraProMax** adalah **tools downloader serbaguna berbasis Python** dengan UI neon futuristik untuk Termux.  
Didesain sebagai **universal video downloader** yang cepat, ringan, dan mendukung **1000+ platform** menggunakan mesin `yt-dlp`.

---

## ✅ Fitur Utama

- 🟣 **Download ALL Video** (TikTok/IG/FB/X/YouTube/CapCut/Reddit/dll)  
- 🟡 **Auto Detect Mode** – tempel link → tools mendeteksi platform otomatis  
- 🔵 **Fast Mode (Multi-thread)** – download banyak video sekaligus  
- 🟢 **Audio Extractor (MP3)** – convert menggunakan FFmpeg  
- 🔮 **Hyper UI v7.1** – neon, matrix, glow, gradient  
- 📦 **Save Metadata + Thumbnail**  
- 📁 **Auto Storage Setup (Android Download folder)**  
- 🧩 **Support 1000+ website via yt-dlp**
